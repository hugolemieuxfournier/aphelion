# Aphelion — site

Le site public d'Aphelion (by Astrolab) : présentation, politique de confidentialité et support, en français et en anglais.
Statique, sans build ni traceur : `index.html`, `confidentialite.html`, `support.html`, `style.css`, `site.js`, `trou.js` (le trou noir de l'intro de l'app, en WebGL).
Publié par GitHub Pages depuis la branche `main`.
